# 字幕规范

> 字幕是这类视频的核心信息载体，规范决定观感。

## 视觉规范

```
字体：Noto Sans CJK SC（思源黑体）Bold
颜色：#FFD700（金黄）
描边：黑色，2px
阴影：黑色，1px，偏移 1px
字号：52px（1080×1920 画面下）
位置：水平居中，距底部 180px（约画面下 1/3）
对齐：Alignment=2（底部居中）
```

## ASS 字幕格式模板

```ass
[Script Info]
Title: {{书名}} 字幕
ScriptType: v4.00+
PlayResX: 1080
PlayResY: 1920

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Default,Noto Sans CJK SC,52,&H00D6D600,&H000000FF,&H00000000,&H00000000,1,0,0,0,100,100,0,0,1,2,1,2,60,60,180,1

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
Dialogue: 0,0:00:00.00,0:00:03.00,Default,,0,0,0,,{{字幕文本1}}
Dialogue: 0,0:00:03.00,0:00:06.00,Default,,0,0,0,,{{字幕文本2}}
...
```

## 颜色编码说明

ASS 字幕颜色格式为 `&HAABBGGRR`：
- AA = 透明度（00=不透明）
- BB = 蓝色通道
- GG = 绿色通道
- RR = 红色通道

| 颜色 | 十六进制 | ASS 编码 |
|------|----------|----------|
| 金黄 #FFD700 | FF D7 00 | `&H00D6D600`（注：ASS 中 D6≈D7） |
| 纯白 #FFFFFF | FF FF FF | `&H00FFFFFF` |
| 描边黑 #000000 | 00 00 00 | `&H00000000` |

> 精确金黄 `#FFD700` = RGB(255,215,0)，ASS 中为 `&H0000D7FF`（BGR 倒序）。
> 实际使用 `&H0000D7FF`。

## 字幕层 vs 金句层

视频内严格区分**字幕层**（口播文字）和**金句层**（书中摘句），二者使用不同的字体、字号和颜色：

| 层 | 内容 | 字体 | 字号 | 颜色 | 位置 |
|----|------|------|------|------|------|
| **字幕层** | 口播旁白文字 | 思源黑体 Bold | 48px | 金黄 `#FFD700` + 黑描边 3.5px | 底部居中（距底 190px） |
| **金句层 ink** | 书页摘句 | 宋体/楷体 | 46px | 深墨色 `#2e1f10` | 画面中上部 |
| **金句层 note** | 场景摘句 | 黑体 | 40px | 白色 `#fff` + 黑描边 3px | 画面角落 |

两者**背景均透明**，不得遮挡画面内容。金句字号均小于口播字幕，不抢主次。

## 字幕写作原则

### 1. 短句优先
```
❌ "阿德勒心理学认为所有烦恼都是人际关系的烦恼"
✅ "所有烦恼，都是人际关系的烦恼"
```

### 2. 叙事性，非标题式
```
❌ "【课题分离】"
✅ "这是谁的课题？"
```

### 3. 每行 ≤16 字，超长换行
```
❌ 自由就是被别人讨厌这才是真正的自由
✅ 自由
   就是被别人讨厌
```

### 4. 金句用完整句，不用片段
```
❌ "课题分离..."
✅ "分清这是谁的课题"
```

## 字幕-旁白关系

| 旁白 | 字幕 | 说明 |
|------|------|------|
| "阿德勒说，所有烦恼，都是人际关系的烦恼。" | "所有烦恼，都是人际关系的烦恼" | 字幕是旁白精华，去掉"阿德勒说" |
| "下次纠结的时候，先问问自己，这是谁的课题？" | "这是谁的课题？" | 字幕提炼核心问题 |
| "这就是被讨厌的勇气教我的事。" | （无字幕） | 过渡句不叠字幕 |

## 时间轴原则

- 字幕出现比旁白早 0.3-0.5 秒（先看后听）
- 每条字幕最少显示 1.5 秒
- 金句字幕显示 3-4 秒
- 两条字幕间隔 ≥0.3 秒（避免连成一片）
- 最后一条字幕在结尾引导处

## 字幕生成工作流

1. 从口播稿提取关键句
2. 按 ≤16 字规则断句
3. 对齐旁白时间轴（配音生成后）
4. 写入 ASS 文件
5. ffmpeg 合成时叠加

# 成片独立终检

> 审核点⑦（成片确认）交给用户之前，必须先派一个**干净上下文的 subagent** 做独立审查。
>
> **制作者对自己的产出有确认偏差，首检永远不能交给用户。**

来源：参考 video-shotcraft `final-review.md`，按图书带货视频场景适配。

## 审查输入

- 最新成片 MP4 和关键帧（从成片抽帧：每段首帧/中帧/末帧）
- 选书档案（`01-profile/book-profile.md`）：书名、作者、带货角度
- 文案简报（`02-script/script-brief.md`）：钩子、观点清单、金句
- 锁定旁白（`02-script/SCRIPT.md`）：8 段螺旋结构
- 分镜（`02-script/STORYBOARD.md`）：画面描述、动效设计
- 口播稿（`02-script/voiceover-text.txt`）
- 音色（`assets/voices/voice-library.json`）
- `references/shot-structure.md`（8 段螺旋结构 + 审美规则清单）
- `references/sound-design.md`（声音设计）
- `references/hyperframes-usage.md`（合成规范）
- `references/deai-checklist.md`（去 AI 味）
- `templates/video-spec.md`（技术规格）

## 检查项

### B — 结构与内容一致性

- B1：成片是否遵循 8 段螺旋结构（钩子+引入书 → 场景1+钩子 → 分析+钩子 → 方案1+新场景2 → 方案2+新场景3 → 方案3 → 总结 → 引导评论）
- B2：引入书段是否包含作者姓名/国籍/领域地位 + 书籍领域地位/销量
- B3：每个金句是否来自 weread 热门划线或书中原文，归属是否清楚
- B4：作者信息是否准确（不能把作者和理论创始人混淆，如岸见一郎 ≠ 阿德勒）

### S — 视觉技术质量

逐条执行 `references/shot-structure.md` 的审美规则清单（R/Q/S/C）。至少检查：

- S1：字幕有效字高 ≥56px（≥5% 帧高），金句 ≥40px
- S2：金句位置是否避开画面主体（抽帧验证每条金句可读）
- S3：插画风格是否全片一致（按选定风格卡），有无镜头偏离
- S4：Ken Burns / 转场是否非线性缓动（无匀速运动）
- S5：光效是否群发（一个镜头最多一次）
- S6：seek-safe：无 `repeat:-1`、`Math.random()`、CSS `animation: infinite`
- S7：无黑帧（heavy overlay >40 个 radial-gradient 的镜头抽样测亮度，<12 为黑帧）

### A — 音频与节奏

- A1：BGM 音量 0.15，不盖人声，淡入 1s / 淡出 2s
- A2：旁白与字幕是否同步（字幕领先旁白 0.3–0.5s）
- A3：SFX（如有）是否钉在真实动作关键帧，有无错位
- A4：片头片尾是否静音（`-an` 去除原视频背景音）

### T — 技术规格

- T1：分辨率 1080×1920
- T2：帧率 30fps CFR
- T3：编码 H.264 + AAC 48kHz
- T4：总时长 ≤244s（基线 199s / 弹性上限 244s，intro + 正文 + outro）
- T5：单镜 ≤15s

### D — 去AI味与安全

- D1：口播稿是否通过 `check-script.py` 20 项全绿
- D2：无医疗承诺、无绝对化、无投资收益承诺
- D3：无诱导导流私域（"加微信""私信领"）
- D4：心理健康话题不诊断承诺，严重情况引导专业帮助

## 报告格式

每条结论使用编号，并给问题附帧号或截图：

```text
B2 ✓ 引入书段包含作者岸见一郎、国籍日本、个体心理学相关。
S1 ✗ 第 340 帧（观点拆解段）：金句字号 36px，低于 40px 下限。
A2 ✗ 第 120 帧：字幕比旁白晚 0.8s 出现，应领先 0.3-0.5s。
T4 ✓ 总时长 199.2s。
```

最后按严重程度列出：
- **必须修复**（✗ 项中的硬伤）
- **建议优化**（⚠ 警告项）
- **无法验证**（缺少输入时标注，不猜测）

**不要用没有证据的"整体不错"代替逐项检查，也不要为了报告好看而全部标记通过。**

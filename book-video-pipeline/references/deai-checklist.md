# 口播稿去 AI 味检查清单

> Step 3d 专用。所有口播稿定稿前必须逐条走完，**每条都要给证据**。
>
> 来源：`humanizer-zh` skill 的 Core Rules + everyday-ai-news-workflow 的公众号硬闸门，按口播场景重写。
>
> 与公众号长文的差别：口播稿是**说出来给人听的**。它天然允许第二人称直呼、允许围绕同一痛点反复加深、允许短句成段——这些是口播手法，不是 AI 腔，不要误删。

## 使用方式

1. 在 Step 3d（humanizer-zh 收尾）时逐条检查。
2. 每条写成 `证据：<正文里的具体句子>` 或 `证据：0 命中`。
3. 禁止写"已优化""已检查""无问题"这类空话。
4. 任何一条不通过，继续改稿，不进入 TTS。
5. 结果写入 `02-script/deai-checklist.md`。

## A. 六类必须清零的 AI 腔

### A1. 替观众下结论

模型爱替观众宣布他此刻的感受和收获。观众自己会感觉，不用被通知。

| 命中示例 | 改法 |
|----------|------|
| 想到这儿，心里是不是一下子轻了 | 删 |
| 那种轻松，你试过一次就知道 | 删 |
| 你会发现，其实没那么难 | 删 |
| 看到这里，你可能已经明白了 | 删 |

判据：句子在描述**观众的内心状态或领悟**，而不是描述事实、场景或动作 → 删。

### A2. 旁白式评价

对自己刚说的话做点评，等于告诉观众"我说得很好"。

| 命中示例 | 改法 |
|----------|------|
| 这句话很关键 / 这个点很重要 | 删，直接说那句话本身 |
| 这本书最狠的一句是 | 去掉"最狠的"，直接引 |
| 这个方法特别实用 | 删，直接给方法 |
| 说到这里，值得停一下 | 删 |

判据：去掉这句，信息不减少 → 删。

### A3. 写作决策外露

把"我要讲个场景了""我们回到书上"这类生产过程说出口。

| 命中示例 | 改法 |
|----------|------|
| 光说没用，说个场景 | 删，直接进场景 |
| 这本书，就在拆这件事 | 删，直接讲内容 |
| 举个例子 / 打个比方 | 删，直接举 |
| 我们先来看…… | 删 |
| 书里还有一句更狠的 | 改成"书里还有一句" |

判据：这句在**announce 下一步要做什么**，而不是内容本身 → 删。

### A4. 先否定再肯定

`不是 A，而是 B` / `不在于 A，而在于 B` / `不只是 A，更是 B`。
口播里这个句式一多，就像在辩论。

| 命中示例 | 改法 |
|----------|------|
| 这不是脾气好，而是太累了 | 你不是脾气好。你只是太累了。（拆成两个短句，保留转折但去掉句式模板） |
| 重要的不是别人怎么看，而是你怎么活 | 你怎么活，才是你的事 |

判据：全片这类句式 ≤1 处。超过就改成直接正向陈述。

> 注意：`你不是 A。你只是 B。` 拆成两句、中间有句号的，属于口播节奏，不算命中。

### A5. 空泛大词与拔高

| 命中示例 | 改法 |
|----------|------|
| 瞬间被点醒 / 彻底改变了我 | 删或改成具体动作 |
| 重新定义 / 颠覆认知 / 治愈 | 删 |
| 从此以后，你会…… | 删（也违反 A1） |
| 这就是成长的意义 | 删 |
| 在这个时代 / 当下这个社会 | 删 |

判据：这个词能套在任何一本书上 → 删。

### A6. 书面语与翻译腔

口播是说的，不是写的。

| 命中示例 | 改法 |
|----------|------|
| 他将告诉你 | 他想告诉你 / 他说 |
| 恰恰说明 | 说明 |
| 对于……来说 | 删，直接说主语 |
| 使得……得以…… | 拆成两句 |
| 基于…… / 围绕……展开 | 换口语说法 |
| 其实 / 事实上（作填充词时） | 删 |

判据：这句话你**不会这么跟朋友说** → 改。

## B. 结构与节奏

### B1. 编号罗列

`第一…第二…第三…第四…` 在口播里像上课。

改法：用口语递进衔接（`说白了` / `所以` / `再往下` / 上句结尾自然带出下句），或直接把观点嵌进场景里讲。

判据：全片 `第一/第二/首先/其次/最后` 0 命中。

### B2. 空转过渡

段落之间的过渡句本身要携带信息或情绪，不能只起"我要换段了"的作用。

判据：删掉这句，上下文能直接接上且不突兀 → 这是空转过渡，删。

### B3. 手法重复

同一个手法（举场景、引金句、反问、"书里说"）在全片用几次？

判据：同一手法 ≥3 次 → 改掉其中一处。

> 注意：**痛点意象的反复加深不算重复**。道歉→翻记录→补表情包→背情绪，这是共鸣设计，是带货口播的核心手法，保留。

### B4. 收束句式雷同

`反常识断言 + 停顿` 这种金句模板，全片不超过 2 次。

## C. 口播与字幕硬约束

| 项 | 要求 | 检查方式 |
|----|------|----------|
| C1 单句长度 | ≤20 字 | 按 `。！？` 切分后统计 |
| C2 无标点串长度 | 连续 <18 字必须有标点 | 按 `。！？；：，、` 切分后统计；**书名号内的字数也算** |
| C3 念得顺 | 出声读一遍，不卡壳、不需要重读 | 人工朗读 |
| C4 引号 | 全角 `""` | 半角 `"` 计数为 0 |
| C5 破折号 | 不用长破折号 `——` | 计数为 0 |
| C6 冒号 | 不连续多句靠冒号展开 | 相邻两句都用冒号 → 改一处 |

自动检查脚本：`scripts/check-script.py`

## D. 内容安全

| 项 | 要求 |
|----|------|
| D1 | 无医疗承诺（治好、根治、痊愈） |
| D2 | 无绝对化用词（一定、必须、全都、永远） |
| D3 | 不贬低读者（你怎么这么…、你太软弱了） |
| D4 | 书中观点与个人感悟区分（标注"书里说""阿德勒说"） |
| D5 | 不承诺播放量、收入、人生改变 |

---

## E. 只删不加原则

Step 3d 是**减法工序**。

- 字数只减不增
- 不补新句子、新场景、新观点
- 不改观点内容和顺序
- 发现内容缺失，退回 Step 3a 重来，不在这一步补

**去 AI 味之后，不许再让任何模型改写。** 后续模型改写会重新引入本清单里的所有问题——这是本项目实际踩过的坑：humanizer-zh 曾被放在 grok 和 DeepSeek 之前，结果两道工序把 AI 腔全加了回来。

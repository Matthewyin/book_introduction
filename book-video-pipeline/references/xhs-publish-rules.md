# 小红书发布合规要点

> 发布前必读。违反平台规则可能导致限流或封号。

## 一、绝对红线（不可触碰）

| 类型 | 禁止内容 | 后果 |
|------|----------|------|
| 医疗承诺 | "治好抑郁""治愈心理疾病" | 限流/删除 |
| 绝对化 | "最好""第一""必须""一定能" | 限流 |
| 投资收益 | "读完月入过万""改变命运" | 限流 |
| 诱导导流 | "加微信""私信领""扫码进群" | 封号风险 |
| 虚假稀缺 | "仅剩3本""最后10个名额" | 限流 |
| 色情低俗 | 擦边内容、性暗示 | 封号 |
| 政治敏感 | 政治评论、领导人 | 封号 |

## 二、心理励志类特别注意

### 心理健康边界

| 可以说 | 不可以说 |
|--------|----------|
| "这本书帮我理解了焦虑" | "这本书治好了我的抑郁症" |
| "阿德勒的观点是..." | "心理学证明你必须..." |
| "如果你也感到内耗" | "你有心理疾病，需要这本书" |
| "自我成长书单" | "精神疾病康复指南" |

### 表达安全清单

- [ ] 不做心理诊断（不说"你是讨好型人格，需要治疗"）
- [ ] 不替代专业咨询（声明"严重情况请寻求专业帮助"）
- [ ] 不夸大效果（不说"读完人生改变"）
- [ ] 用"我/有些人/书中观点"代替"你一定"
- [ ] 书中观点与个人感悟区分清楚

## 三、带货合规

### 商品链接
- 使用小红书官方店铺/选品中心
- 不在正文留外部购买链接
- 不在评论区发淘宝/京东链接

### 价格表述
| 可以 | 不可以 |
|------|--------|
| "不到一杯咖啡的钱" | "全网最低价" |
| "性价比很高" | "比官方便宜50%" |
| "官方店铺有售" | "私我拿内部价" |

## 四、标签合规

- 标签与内容相关，不蹭无关热搜
- 每篇标签 5-10 个为宜
- 不重复堆砌同一标签
- 不使用违规缩写规避检测（如 V x = 微信）

## 五、版权合规

| 元素 | 规范 |
|------|------|
| 书封图片 | 可使用官方书封做展示，不做二次销售 |
| 书内文字 | 摘录不超过合理引用范围（几句话） |
| 背景音乐 | 使用无版权/已授权 BGM |
| 插画素材 | AI 生成或自有版权 |
| 他人评论 | 不截图用户评论做内容（隐私） |

## 六、账号安全

### 避免限流的行为
- 不频繁删除重发
- 不短时间内大量发布
- 不刷赞刷评论
- 不互赞互粉群
- 不搬运他人内容

### 发布频率建议
- 新号：每天 1-2 条，间隔 6 小时以上
- 稳定期：每周 3-5 条
- 同一书的不同角度视频：间隔 2-3 天

## 七、敏感词替换表

| 敏感词 | 替换建议 |
|--------|----------|
| 微信 | 平台内私信 |
| 加群 | 官方互动工具 |
| 优惠码 | 官方店铺 |
| 治疗 | 理解/应对/缓解 |
| 抑郁症 | 情绪低落/内耗 |
| 焦虑症 | 焦虑感/压力 |

## 八、发布前最终检查

```
□ 标题 ≤20 字，有钩子，无违规词
□ 简介无外部链接、无微信号
□ 标签 5-10 个，相关不堆砌
□ 视频无水印（除自己的 logo）
□ 封面图清晰，无夸大文案
□ 无医疗/投资/绝对化承诺
□ 书名作者信息准确
□ 已使用平台内店铺/选品工具
```

# 风格增强词库（style-vocabulary.md）

> **用途**：写风格卡或场景提示词时，从本词库挑「质感微调」短语，提升画面完成度。
> **来源**：提炼自社区 GPT Image 2 提示词库（YouMind-OpenLab/awesome-gpt-image-2，
> CC BY 4.0），均为社区实测过的成熟写法。
> **铁律**：风格卡锁定主描述 + 五色色板，本词库只提供"质感/光线/笔触"的可选微调项，
> 不得用词库词汇替换风格卡的核心描述——否则色板会漂移。

---

## 一、动漫 / 水彩质感（配合 cute-anime-girl 风格卡）

| 场景 | 推荐短语 |
|------|---------|
| 动漫角色主体 | 细腻线条、平滑的赛璐珞上色、柔和的腮红调 |
| 水彩插画 | 水彩晕染、温暖的米色阴影、细腻的纸张纹理 |
| 水彩+动漫画风 | 水彩墨水动漫风格、绘画感植被、自然材质渲染 |
| 柔软治愈感 | 柔和圆润线条、扁平色块加轻渐变、光晕柔化边缘 |
| 光影 | 柔和的腮红调、光晕柔化边缘、细腻阴影 |

## 二、写实 / 电影质感（配合 cinematic-girl 风格卡）

| 场景 | 推荐短语 |
|------|---------|
| 镜头 | 85mm 镜头、f/1.4–f/2.0 光圈、浅景深、奶油般虚化 |
| 胶片感 | 细腻的胶片颗粒、轻微传感器噪点、电影级色调 |
| 皮肤质感 | 真实皮肤纹理、可见毛孔、细微瑕疵、自然高光与阴影 |
| 光线 | 柔和的金色暖光、午后自然光、柔和的侧向晨雾光、柔和斑驳的光 |
| 氛围 | 电影剧照感、日系生活流电影静帧、温暖通透 |

## 三、光线 / 氛围微调（通用）

| 想要的效果 | 推荐短语 |
|-----------|---------|
| 清晨治愈 | 清晨阳光透过窗户洒进来，光线明亮温暖、干净通透 |
| 夜晚安静 | 暖色台灯的光晕，角落深阴影，光只落在主体上 |
| 梦幻柔和 | 柔和的漫射光、光晕、粉尘在光束中漂浮（dust motes floating in the light beam） |
| 情绪张力 | 冷暖光对比（暖台灯 vs 冷手机屏光），硬阴影强化情绪 |
| 通透清新 | 明亮漫射光、白色调、光斑洒落桌面 |

## 四、主体细节铺陈（给场景/道具加具体度）

| 想要的效果 | 推荐短语 |
|-----------|---------|
| 旧物质感 | 磨损的皮革扶手椅，扶手搭着折叠针织毯 |
| 生活痕迹 | 叠放的书，顶封有咖啡杯渍 |
| 动感 | 薄纱窗帘在微风里轻轻飘动 |
| 光影细节 | 阳光光束里漂浮的尘埃颗粒 |
| 材质对比 | 粗糙纸张 + 光滑玻璃 + 哑光木质，三种质感同框 |

## 五、负面质感（写进禁止项）

- 避免：厚重油画感、扁平矢量风、塑料感皮肤、过度磨皮
- 动漫卡禁：3D 渲染、厚涂油画、写实照片化
- 写实卡禁：动漫、赛璐珞、插画、水彩、3D

---

## 使用规则

1. **风格卡**（`templates/styles/*.md`）只改一次：从词库选 2-3 个质感短语并入"Style"段。
2. **场景提示词**（DeepSeek 写 scene.md）可从词库选光线短语进 `Lighting` 字段，
   但**不写风格词**（风格词在风格卡里，重复写会漂）。
3. **新增词库条目**：任何在出图中实测有效的短语，补进来并在来源标注出处。

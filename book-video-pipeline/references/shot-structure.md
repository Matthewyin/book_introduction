# 口播结构与分镜标准（唯一控制源）

> **本文件是视频叙事结构的唯一定义**。所有口播稿、分镜、文案简报必须遵循此结构，不得在其他文件中重复定义。
>
> **8 段螺旋结构** · 1.1 倍速配音 · 正文基线 ~195s（弹性上限 ~240s）。

## 8 段螺旋结构总览

核心逻辑：**场景 → 方案 → 更深场景 → 更深方案**，螺旋递进。
每个痛点当场配解药，段末用融入式钩子驱动观众往下看。

```
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│ 钩子 │场景1 │ 分析 │方案1 │方案2 │方案3 │ 总结 │结尾  │
│+引入书│+钩子 │+钩子 │+新场景│+新场景│      │场景- │引导  │
│      │      │      │  2   │  3   │      │ 方案 │评论  │
│ 0-12 │12-30 │30-50 │50-90 │90-135│135- │165-  │185-  │
│  ~36 │ ~55  │ ~60  │~120  │~135  │165  │185   │195   │
│  字  │ 字   │ 字   │ 字   │ 字   │~90字│~60字 │~15字 │
└──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
 intro 1.0s                                         outro 3.2s
```

| # | 段落 | 时间 | 字数 | 占比 | 目的 |
|---|------|------|------|------|------|
| 1 | **钩子+引入书** | 0–12s | ~36 字 | 6% | 12 秒内引入书，零冗余进场 |
| 2 | **场景1+钩子** | 12–30s | ~55 字 | 10% | 第一个痛点场景入戏 + 段末融入式钩子 |
| 3 | **分析+钩子** | 30–50s | ~60 字 | 10% | 书中理论解释"为什么" + 段末融入式钩子 |
| 4 | **方案1+引入场景2** | 50–90s | ~120 字 | 21% | 方法1 + "如果xxx怎么办"过渡到更深场景 |
| 5 | **方案2+引入场景3** | 90–135s | ~135 字 | 24% | 方法2 + "如果xxx怎么办"过渡到最深场景 |
| 6 | **方案3** | 135–165s | ~90 字 | 16% | 方法3（收束） |
| 7 | **总结（场景-方案）** | 165–185s | ~60 字 | 10% | 3 组场景-方案对照，强化记忆/收藏 |
| 8 | **引导评论** | 185–195s | ~15 字 | 3% | 1 句互动提问 |
| | **合计（基线）** | **~195s** | **~570 字** | 100% | + intro 1.0s + outro 3.2s = ~199s |

> 字数基于 1.1 倍速（约 3.0 字/秒）。基线总字数 ~570 字。

## 弹性时长机制

| 档位 | 正文时长 | 总字数 | 总时长 | 触发条件 |
|------|----------|--------|--------|----------|
| **基线（默认）** | ~195s | ~570 字 | ~199s | 默认按此写 |
| **弹性（上限）** | ~240s | ~720 字 | ~244s | 段间钩子全部通过审核点③后才解锁 |

- 写稿默认按基线 ~570 字写。
- 审核点③（口播稿审核）时判定段间钩子是否成立：若全部成立，允许各段适当展开至上限 720 字。
- `check-script.py` 字数红线 = 720 字（硬上限），超 570 字时打印"需钩子审核通过"警告。

## 情绪曲线

```
钩子+书 → 场景1 → 分析 → 方案1+新场景 → 方案2+新场景 → 方案3 → 总结对照 → 引导评论
紧张/好奇  压抑/共鸣  恍然  释怀→新焦虑    释怀→新焦虑   收束    峰值/记忆   互动
   ↓          ↑钩子     ↑钩子    ↑↓如果…        ↑↓如果…       ↓         ↑全片最高
```

## 融入式钩子（核心写法）

段 2、段 3 末尾的"钩子"**不是生硬提问**，而是把疑问埋进陈述句，让听众脑子里自动冒出问题。

### 铁律
- ❌ 禁止生硬提问："那怎么办？""为什么呢？""为什么会这样？"
- ✅ 必须融入陈述：把问题的答案**留白**，让听众自己产生疑问
- ✅ 下一段开头顺势承接这个隐性疑问，不重复问

### 对比示例

| 段落 | ❌ 生硬（禁止） | ✅ 融入（要求） |
|------|----------------|----------------|
| 段2末→段3 | "为什么会这样？书里说……" | "话一出口，就像上了锁。可这把锁的钥匙，连你自己都不知道在哪。"（听众自然想"怎么开锁？"） |
| 段3末→段4 | "那怎么办呢？" | "不是你脸皮薄，是有人悄悄按了你身上的一个开关。"（听众自然想"什么开关？怎么关掉？"） |

### "如果 xxx 怎么办"过渡（段4/段5末）

段 4、段 5 末尾用"如果 xxx 怎么办"预判观众反驳，引入更深场景：
- 段4末："可要是对方根本不给你思考的时间呢？"→ 引入场景2（更强势的施压）
- 段5末："可万一你已经答应了，话都说出口了呢？"→ 引入场景3（已经陷入的困境）

## 各段详解

### 1. 钩子+引入书（0–12s，~36 字）

**目的**：12 秒内引入书，零冗余进场。

**结构**：1 句钩子（痛点/悬念/反常识）+ 1 句紧凑背书。

**必须包含**（紧凑塞入，不展开）：
- 书名 + 作者姓名 + 领域地位 + 销量/影响力（四要素，用一句话压缩）

**示例**：
> 越讨好越不被尊重。
> 个体心理学创始人阿德勒，在《被讨厌的勇气》里给了答案。

**画面**：深色渐变背景 / 书封特写，无人物，纯氛围。

### 2. 场景1+钩子（12–30s，~55 字）

**目的**：让观众"入戏"，产生共鸣。

- 用 1 个生活化场景，演绎读者真实困境
- 第二人称"你"直击痛点
- 不说教，只白描
- **段末融入式钩子**：把疑问埋进陈述，驱动往下看

### 3. 分析+钩子（30–50s，~60 字）

**目的**：用书中理论解释"为什么会这样"，建立"这本书懂我"的信任。

- 引用书中核心概念解释场景1 的成因
- 不堆术语，用比喻让概念可感
- **段末融入式钩子**：引出"那怎么破解"，但不明问

### 4. 方案1+引入场景2（50–90s，~120 字）

**目的**：第一个方法 + 过渡到更深场景。

- 给出书中方法1（具体可执行）
- 用"你可以试试……"的引导句式
- **段末"如果 xxx 怎么办"**：预判观众反驳，引入场景2（更难的情况）

### 5. 方案2+引入场景3（90–135s，~135 字）

**目的**：第二个方法（应对场景2）+ 过渡到最深场景。

- 方法2 应对场景2 的更难情况
- **段末"如果 xxx 怎么办"**：引入场景3（最深层困境，如"已经陷进去了"）

### 6. 方案3（135–165s，~90 字）

**目的**：第三个方法（应对场景3），收束。

- 方法3 解决最深层困境
- 三招给完，观众带走得走

### 7. 总结（165–185s，~60 字）

**目的**：场景-方案对照，强化记忆，驱动收藏。

- 用 3 组对照浓缩全片："场景→方案"快速复盘
- 句式整齐，便于记忆
- 这一段是全片"收藏价值"的核心

**示例**：
> 顺口答应？先把"行我来"换成"我半小时回你"。
> 被催着表态？一句"我考虑下"就是刹车。
> 已经答应？问自己"今天重选我还答应吗"——不会就撤。

### 8. 引导评论（185–195s，~15 字）

**目的**：驱动评论互动。

- 1 句互动提问（明确引导评论）
- 提问要具体、跟场景相关，不要泛泛"你怎么看"

| 类型 | 示例 |
|------|------|
| 经验型 | "你上一次顺口答应，搭进去了几天？" |
| 选择型 | "最难拒绝的那个人，是老板还是家人？" |
| 共鸣型 | "哪一句话让你最想撤回？评论区告诉我。" |

## 螺旋循环可伸缩

默认 3 场景 × 3 方案。书目内容或时长不足时，可收缩：

| 档位 | 结构 | 正文时长 | 适用 |
|------|------|----------|------|
| **标准（默认）** | 3 场景 × 3 方案 | ~195s | 方法论/干货书（多场景多方法） |
| **紧凑** | 2 场景 × 2 方案 + 1 深化 | ~165s | 单一主题书（场景少但深） |
| **弹性展开** | 3 场景 × 3 方案 + 各段展开 | ~240s | 钩子全成立时解锁 |

> 由 `script-brief.md` 按书目内容预判，审核点②确认。

## 字幕-旁白对齐原则

1. **字幕 ≠ 旁白全文字**：字幕是旁白的精华提炼，每条字数上限以 `templates/video-spec.md` 为准
2. **字幕领先旁白 0.3–0.5 秒**：观众先看到再听到
3. **金句/总结段停留更久**：3–4 秒，让观众记住
4. **过渡句可以无字幕**：只在关键信息处叠字幕

## 能量节奏曲线

8 段结构是螺旋递进的能量弧线。参照电影感宣传片的能量骨架（来源：video-shotcraft `sequences/promo-energy-arc.md`）：

```
钩子+书(中高) → 场景1(高) → 分析(低,建信任) → 方案1+新场景(爬升) → 方案2+新场景(爬升) → 方案3(收束) → 总结(峰值,记忆) → 引导评论(互动)
                   ↑钩子          ↑钩子          ↑↓ 如果…             ↑↓ 如果…                ↓              ↑全片最高
```

**关键节奏原则**：

| 原则 | 说明 |
|------|------|
| **宁慢勿快** | 初版默认放慢一档。历史反馈全部指向"放慢/停留"，从未有一次"太快了"。主体动作弧 ≥3s |
| **关键信息落定后必须呼吸** | 金句、书名、作者名落定后静止 ≥1s 再切镜。呼吸停顿优先给关键信息 |
| **速度感来自加速度** | Ken Burns 推拉、转场淡入一律非线性缓动，匀速运动读作廉价 PPT |
| **方案段高低交替** | 每个"如果 xxx 怎么办"是一个能量小峰值，方案解答是回落，形成呼吸感 |
| **总结是全片能量峰值** | 场景-方案对照是观众"想截图收藏"的瞬间，默认加码 |
| **段末钩子是注意力锚点** | 每个段末钩子后必须紧跟切镜，不拖 |

## 审美规则清单（判例式）

> 来源：融合 video-shotcraft `aesthetic-rules.md` 的通用准则，按图书带货视频场景适配。
>
> **使用方式**：每条 = 规则 + 自检问题。审核点⑦（成片确认）前逐条过一遍，输出自检报告：`编号 ✓` 或 `编号 ✗(位置)`。
>
> 编号体系：R(节奏) / Q(质感·运镜·构图) / S(声音) / C(文案)。

### 节奏（R）

| 编号 | 规则 | 自检 |
|------|------|------|
| R1 | 关键信息落定后静止 ≥1s 再切镜（金句、书名、作者名、总结对照） | 每个"想让观众记住的画面"是否有完整静止时刻？ |
| R2 | Ken Burns / 转场一律非线性缓动，禁匀速直线运动 | 有没有任何元素在做匀速运动？ |
| R3 | 节奏宁慢勿快，初版默认放慢一档，主体动作弧 ≥3s | 把每个镜头当第一次看：哪里没看清？ |
| R4 | 段末钩子后必须紧跟切镜，不拖 | 每个段末钩子后面是不是马上切到新画面？ |

### 质感·运镜·构图（Q）

| 编号 | 规则 | 自检 |
|------|------|------|
| Q1 | 生图分辨率统一为 1080×1920，center-crop 避免构图偏移 | 素材分辨率是否一致？缩放后构图有无偏移？ |
| Q2 | **字幕有效字高 ≥5% 帧高**（1080×1920 画面下 ≥56px），金句 ≥40px | 抽含字幕的镜头缩到 480px 宽（模拟手机小窗）：每句还读得清吗？ |
| Q3 | 光效宁缺毋滥：一个镜头最多给主角一次光晕，禁群发 sparkle | 全片光效出现次数有没有超过"主角元素一次"？ |
| Q4 | 开场只给一个主角：钩子段聚焦单一痛点，不堆叠多个场景 | 开场镜头有几个"想让观众看"的东西？ |
| Q5 | 金句位置必须避开画面主体（杯子、人脸、书脊），渲染后抽帧验证 | 每条金句落在什么位置？有没有被画面元素遮挡？ |
| Q6 | 插画风格保持一致：全片统一选定风格卡，不混入其他风格 | 有没有镜头的风格偏离了风格卡？ |

### 声音（S）

| 编号 | 规则 | 自检 |
|------|------|------|
| S1 | BGM 音量 0.15 不盖人声，淡入 1s、淡出 2s | 闭眼听：BGM 有没有盖住旁白？ |
| S2 | SFX（如有）按电影类型选音效，禁游戏音包音色（详见 `references/sound-design.md`） | 音效像真实世界的声音还是游戏提示音？ |
| S3 | 声音在画面锁定后做；时间线一动，SFX 全表重钉 | 本轮有没有镜头时长变化？SFX 重对了吗？ |

### 文案（C）

| 编号 | 规则 | 自检 |
|------|------|------|
| C1 | 字幕是旁白精华提炼，每条字数以 video-spec.md 为准，不用标题式 | 字幕有没有超长？有没有标题式（"【课题分离】"）？ |
| C2 | 段1 引入书必须含书名+作者+领域地位+销量（四要素，紧凑塞入） | 四要素是否齐全？ |
| C3 | 观点归属清楚：书中观点标注"书里说"，不加个人绝对化判断 | 书中观点和个人感悟有没有混为一谈？ |
| C4 | 段末钩子必须融入式，禁止生硬提问（"那怎么办？""为什么？"） | 段末是不是在生硬提问？有没有把疑问埋进陈述？ |
| C5 | "如果 xxx 怎么办"过渡必须预判观众真实反驳，不凑数 | 段4/段5 末的"如果"是不是观众真的会问的问题？ |

## 节奏检查清单

- [ ] 段1 在 12 秒内引入书（含书名+作者+领域地位+销量）
- [ ] 段2/段3 末尾是融入式钩子（非生硬提问）
- [ ] 段4/段5 末尾有"如果 xxx 怎么办"过渡到更深场景
- [ ] 3 个场景层层递进（不是平行罗列）
- [ ] 3 个方案分别对应 3 个场景

- [ ] 结尾引导明确（1 个互动提问）
- [ ] 无超过 15 秒的"无变化"画面
- [ ] 总字数 ≤570 字（基线）/ ≤720 字（弹性，需钩子审核通过）

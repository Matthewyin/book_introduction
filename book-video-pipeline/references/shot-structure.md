# 口播结构与分镜标准（唯一控制源）

> **本文件是视频叙事结构的唯一定义**。所有口播稿、分镜、文案简报必须遵循此结构，不得在其他文件中重复定义。
>
> 7 段结构 · 1.2 倍速配音 · 总时长 ≤200 秒（intro 1.0s + 正文 ~195s + outro 3.2s）。

## 7 段结构总览

```
┌──────┬──────┬───────┬──────┬──────┬──────┬──────┐
│ 钩子 │扎心  │引入书 │场景  │观点  │方法  │结尾  │
│      │场景  │       │演绎  │拆解  │实操  │引导  │
│ 6s   │24s   │20s    │40s   │60s   │30s   │15s   │
│ ~18字│~72字 │~60字  │~120字│~180字│~90字 │~30字 │
└──────┴──────┴───────┴──────┴──────┴──────┴──────┘
 intro 1.0s                                    outro 3.2s
```

| # | 段落 | 时间 | 字数 | 目的 |
|---|------|------|------|------|
| 1 | **钩子** | 0–6s | ~18 字 | 3 秒内留住观众 |
| 2 | **扎心场景** | 6–30s | ~72 字 | 入戏，产生共鸣 |
| 3 | **引入书** | 30–50s | ~60 字 | 作者介绍 + 书籍介绍 |
| 4 | **场景演绎** | 50–90s | ~120 字 | 书中核心情境画面化 |
| 5 | **观点拆解** | 90–150s | ~180 字 | 3–5 个金句 + 展开 |
| 6 | **方法实操** | 150–180s | ~90 字 | 可执行步骤，驱动收藏 |
| 7 | **结尾引导** | 180–195s | ~30 字 | 1 个行动 + 互动提问 |
| | **正文合计** | **~195s** | **~570 字** | + intro 1.0s + outro 3.2s = ~199s |

> 字数基于 1.2 倍速（约 3.0 字/秒）。总字数 ≤570 字。

## 情绪曲线

```
钩子      → 扎心场景  → 引入书   → 场景演绎  → 观点拆解  → 方法实操  → 结尾引导
紧张/好奇    压抑/共鸣   好奇/信任   沉浸/代入   恍然/释怀   自信/可行   期待/行动
```

## 各段详解

### 1. 钩子（0–6s，~18 字）

**目的**：3 秒内留住观众。

| 钩子类型 | 句式 | 示例 |
|----------|------|------|
| 痛点型 | "你是不是也{{痛点}}？" | "你是不是也在讨好所有人？" |
| 悬念型 | "{{反常现象}}，为什么？" | "越讨好的人，越不被尊重，为什么？" |
| 反常识 | "{{常识}}？错。" | "好人有好报？心理学说未必。" |
| 故事型 | "有个人{{故事开头}}" | "有个年轻人，问哲人一个问题…" |
| 数字型 | "{{数字}}个{{方法}}" | "3 步摆脱讨好型人格" |

**画面**：深色渐变背景，无人物，纯氛围。

### 2. 扎心场景（6–30s，~72 字）

**目的**：让观众"入戏"，产生共鸣。

- 用 2–3 个生活化场景，演绎读者真实困境
- 第二人称"你"直击痛点
- 不说教，只白描

### 3. 引入书（30–50s，~60 字）

**目的**：建立信任，让观众觉得"这本书能帮我"。

**必须包含**：
- **作者介绍**：姓名、国籍、在该领域的地位（如"个体心理学创始人"）
- **书籍介绍**：在领域的地位、销量/影响力（如"全球销量超 XX 万册""XX 领域入门首选"）

**承接句**：必须有过渡（"如果你也想摆脱……这本书会帮到你"），不能硬转。

### 4. 场景演绎（50–90s，~120 字）

**目的**：把书中核心情境画面化，让观众"看见"书的内容。

- 用 3–4 个场景画面，演绎书中情境
- 每个画面 10–12 秒，配 2–3 句旁白
- 字幕用叙事句式，不用标题式

### 5. 观点拆解（90–150s，~180 字）

**目的**：给出"恍然大悟"的洞察。

- 3–5 个核心观点，每个用金句开头
- 每个观点配 1 个隐喻画面
- 金句用透明背景文字层（ink/note 样式，详见 `references/hyperframes-usage.md`）

### 6. 方法实操（150–180s，~90 字）

**目的**：给出"可带走"的行动方案，驱动收藏。

- 1 个具体方法，拆成 2–3 步
- 配书封/内页展示画面
- 用"你可以试试…"的引导句式

### 7. 结尾引导（180–195s，~30 字）

**目的**：驱动互动（评论/收藏/关注）。

- 1 个明确行动 + 1 句互动提问
- 引导方式：评论提问 / 收藏清单 / 关注系列

| 引导类型 | 文案示例 |
|----------|----------|
| 评论型 | "评论区告诉我：你最想改变的一件事" |
| 收藏型 | "收藏这条视频，下次焦虑时拿出来看" |
| 关注型 | "关注我，每周一本心理好书" |

## 字幕-旁白对齐原则

1. **字幕 ≠ 旁白全文字**：字幕是旁白的精华提炼，每条 ≤14 字
2. **字幕领先旁白 0.3–0.5 秒**：观众先看到再听到
3. **金句停留更久**：3–4 秒，让观众记住
4. **过渡句可以无字幕**：只在关键信息处叠字幕

## 节奏检查清单

- [ ] 开头 6 秒内有明确钩子
- [ ] 前 15 秒已进入扎心场景（不拖沓）
- [ ] 引入书段包含作者国籍/地位 + 书籍领域地位/销量
- [ ] 每 15–20 秒有一次信息推进（新画面或新观点）
- [ ] 金句有足够停留时间（≥3 秒）
- [ ] 方法部分有可执行的步骤
- [ ] 结尾引导明确（1 个行动）
- [ ] 无超过 15 秒的"无变化"画面
- [ ] 总字数 ≤570 字（1.2 倍速下 ≤195s 正文）

# 分镜结构标准

> 所有视频遵循统一的三段式叙事结构，保证完播率和带货效果。

## 180 秒结构模板

```
┌─────────────────────────────────────────────────────┐
│  开头钩子  │        正文（场景+观点+方法）         │ 结尾 │
│   5s      │                 145s                   │ 10s  │
│  3%       │                 91%                    │ 6%   │
│           │                                       │      │
│ 悬念/痛点  │ 场景演绎→观点拆解→方法实操              │ 引导  │
│ 1 个画面   │ 8-12 个画面                           │ 1画面 │
└─────────────────────────────────────────────────────┘
```

## 各段详解

### 开头钩子（0-5s）

**目的**：3 秒内留住观众。

| 钩子类型 | 句式 | 示例 |
|----------|------|------|
| 痛点型 | "你是不是也{{痛点}}？" | "你是不是也在讨好所有人？" |
| 悬念型 | "{{反常现象}}，为什么？" | "越讨好的人，越不被尊重，为什么？" |
| 反常识 | "{{常识}}？错。" | "好人有好报？心理学说未必。" |
| 故事型 | "有个人{{故事开头}}" | "有个年轻人，问哲人一个问题…" |
| 数字型 | "{{数字}}个{{方法}}" | "3 步摆脱讨好型人格" |

**画面**：
- 深色渐变背景（品牌 palette）
- 无人物，纯氛围
- 黄字钩子居中渐入

### 正文 Part 1：场景演绎（5-50s）

**目的**：让观众"入戏"，产生共鸣。

**结构**：
- 用 3-4 个场景画面，演绎书中核心情境
- 每个画面 10-12 秒，配 2-3 句旁白
- 字幕用叙事句式，不用标题式

**示例**（《被讨厌的勇气》）：
```
画面1（5-18s）：昏暗办公室，一人对着电脑，表情疲惫
旁白："深夜十一点，她还在改方案。不是因为热爱，是怕同事觉得她不够努力。"

画面2（18-32s）：聚会场景，一群人笑着，主角在角落陪笑
旁白："朋友聚会，她笑着附和每个话题。回家路上，却说不出一句话。"

画面3（32-50s）：对镜场景，镜中人面无表情
旁白："她活成了所有人期待的样子，唯独丢了自己的。"
```

### 正文 Part 2：观点拆解（50-110s）

**目的**：给出"恍然大悟"的洞察。

**结构**：
- 3-5 个核心观点，每个用金句开头
- 每个观点配 1 个隐喻画面
- 金句用黄字放大，其余正常字幕

**示例**：
```
观点1（50-65s）：
  金句字幕："所有烦恼，都是人际关系的烦恼"
  画面：两个人物，一人明亮一人阴影
  旁白展开（2-3句）

观点2（65-82s）：
  金句字幕："课题分离：这是谁的课题？"
  画面：一条线分开两个区域
  旁白展开

观点3（82-100s）：
  金句字幕："自由，就是被别人讨厌"
  画面：人物走向开阔的风景
  旁白展开
```

### 正文 Part 3：方法实操（110-150s）

**目的**：给出"可带走"的行动方案，驱动收藏。

**结构**：
- 1 个具体方法，拆成 2-3 步
- 配书封/内页展示画面
- 用"你可以试试..."的引导句式

**示例**：
```
画面（110-125s）：书桌特写，翻开的书 + 手写笔记
旁白："阿德勒给了一个方法，叫课题分离。"

画面（125-140s）：三步法图示（插画呈现）
旁白："下次纠结时，先问自己三个问题：这是谁的课题？答案的那个人，有没有能力解决？如果答案不是你，就放手。"

画面（140-150s）：书封面特写
旁白："这就是《被讨厌的勇气》教我的事。"
```

### 结尾引导（150-160s）

**目的**：驱动互动（评论/收藏/关注）。

**画面**：
- 品牌色背景
- logo + 引导文案
- 行动召唤

**引导文案**：
- 评论型："评论区告诉我：你最想改变的一件事"
- 收藏型："收藏这条视频，下次焦虑时拿出来看"
- 关注型："关注我，每周一本心理好书"

## 字幕-旁白对齐原则

1. **字幕 ≠ 旁白全文字**：字幕是旁白的精华提炼，每条 ≤16 字
2. **字幕领先旁白 0.3-0.5 秒**：观众先看到再听到
3. **金句字幕停留更久**：3-4 秒，让观众记住
4. **过渡句可以无字幕**：只在关键信息处叠字幕

## 节奏检查清单

- [ ] 开头 5 秒内有明确钩子
- [ ] 前 15 秒已进入场景（不拖沓）
- [ ] 每 15-20 秒有一次信息推进（新画面或新观点）
- [ ] 金句有足够停留时间（≥3 秒）
- [ ] 方法部分有可执行的步骤
- [ ] 结尾引导明确（1 个行动）
- [ ] 无超过 15 秒的"无变化"画面

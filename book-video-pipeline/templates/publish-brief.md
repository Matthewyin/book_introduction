```

✍️ 岸见一郎 / 古贺史健

阿德勒说：所有烦恼，都是人际关系的烦恼。
这本书用一场青年与哲人的对话，讲透了为什么我们活得不自由。

「自由就是被别人讨厌。」

试着做一次课题分离：
下次纠结时，先问自己——这是谁的课题？

💬 评论区告诉我：你最想改变的一个习惯是什么？
```

## 合规检查

- [ ] 无医疗诊断承诺（"治好你的抑郁"）
- [ ] 无绝对化表述（"一定能""必须"）
- [ ] 无投资收益承诺
- [ ] 无诱导加微信/导流私域
- [ ] 无虚假稀缺（"仅剩3本"）
- [ ] 书名、作者、出版社信息准确
- [ ] 标签与内容相关，不堆砌

## 写作约束

| 约束 | 要求 |
|------|------|
| 总字数 | 基线 ≤570 字 / 弹性 ≤720 字（段间钩子全通过审核后才解锁弹性） |
| 结构 | 8 段螺旋：钩子+引入书 → 场景1+钩子 → 分析+钩子 → 方案1+新场景2 → 方案2+新场景3 → 方案3 → 总结（场景-方案）→ 引导评论（详见 `references/shot-structure.md`） |
| 段1 引入书 | 12 秒内引入；必须含书名+作者+领域地位+销量（四要素） |
| 段末钩子 | 段2/段3 用融入式（禁止生硬提问）；段4/段5 用"如果 xxx 怎么办" |
| 螺旋递进 | 3 场景 × 3 方案层层递进（非平行罗列）；可伸缩（2×2+1 紧凑档） |
| 单句长度 | ≤20 字，口语化，可断句 |
| 安全 | 无医疗承诺、无"治好/一定/必须"等绝对化用词、不贬低读者 |
| 段8 结尾 | 1 句互动提问（明确引导评论） |

## 与分镜的关系

- 每个 `## Line N` 对应 STORYBOARD.md 的一个或多个 `## Frame N`。
- 缩进块里的文本是**唯一喂给 TTS 的内容**，其余都是给人看的注释。
- `**Time:**` 只是预估参考，Step 5 会用音频静音检测算出真实时间轴，覆盖这里的值。
- 另需产出一份单行纯文本 `voiceover-text.txt` 供 TTS 脚本读取（去掉所有 markdown 标记）。

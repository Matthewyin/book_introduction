# 封面图提示词模板

> 视频封面用于小红书笔记首图，决定点击率。

## 封面规格

- 尺寸：1080×1440（小红书竖版 3:4）
- 格式：PNG / JPG
- 文件：`cover/cover.png`

## 封面设计原则

| 原则 | 说明 |
|------|------|
| 视觉冲击 | 大字标题 + 书封实物 + 高对比色 |
| 信息明确 | 用户 0.3 秒内看懂"这是什么书、解决什么问题" |
| 情绪触发 | 用痛点词或反差词勾起点击欲 |
| 品牌一致 | 与视频画面风格统一 |

## 封面提示词（baoyu-image-gen）

```
风格：{{电影感插画 / 实拍合成 / 极简文字封面}}
尺寸：9:16（竖版）
主体：
  - 书封面居中或手持展示
  - 大字标题叠加："{{钩子文案，≤12字}}"
  - 副标题（可选）："{{如：阿德勒心理学入门}}"
配色：{{从 config.yaml 的 palettes 中选择}}
氛围：{{如：温暖治愈 / 深沉思考 / 强烈冲击}}
```

## 封面文案库

### 痛点型（推荐）
- "为什么你总是讨好别人？"
- "别再为别人的情绪买单了"
- "讨好型人格自救指南"

### 反差型
- "越讨好，越不被尊重"
- "被讨厌，才是自由的开始"

### 权威型
- "阿德勒心理学入门首选"
- "日本亚马逊心理学 No.1"

## 封面 A/B 方案

| 方案 | 主视觉 | 标题 | 适用场景 |
|------|--------|------|----------|
| A | 书封 + 大字钩子 | 痛点型 | 新号冷启动 |
| B | 插画场景 + 小字书名 | 故事型 | 系列内容 |
| C | 真人手持书 + 标注 | 信任型 | 有真人素材时 |

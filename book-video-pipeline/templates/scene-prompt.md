# 场景插画提示词模板

> 每个分镜对应的 AI 插画提示词，用 baoyu-image-gen（即梦后端）生成。

## 生成规格

- 尺寸：1080×1920（竖版 9:16）
- 后端：jimeng（即梦）
- 质量：high
- 风格锚点：参考 ep001 的电影感叙事插画风格

## 统一风格前缀

所有场景插画使用以下统一前缀，保证系列视频风格一致：

```
电影感叙事插画，{{书籍调性描述}}，柔和光影，竖版构图 9:16，
色彩浓郁有层次，人物为插画风（非写实照片），
画面留出底部 1/3 空间用于叠加字幕，
```

## 风格一致性检查

生成所有场景后，检查：

- [ ] 配色统一（同一 palette）
- [ ] 人物形象一致（如同一角色出现多次）
- [ ] 光影风格统一
- [ ] 底部留白足够叠加字幕
- [ ] 无水印、无文字（文字由后期叠加）

## 批量生成建议

1. 先生成 1 张测试风格，确认后再批量生成
2. 使用相同的随机种子（如即梦支持）保持一致性
3. 每个场景生成 2-3 张，挑选最佳

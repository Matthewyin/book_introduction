## 写作约束

| 约束 | 要求 |
|------|------|
| 总字数 | 120-175 字（含引入句 ~28 字 + 金句 90-150 字，≤60 秒） |
| 金句数 | 3-5 句 |
| 单句长度 | 15-35 字（适合字幕 + 朗读） |
| 引入句 | 固定模板："今天分享的书籍是：《{书名}》作者：{作者}。书中有这样一句话——" |
| 金句来源 | 微信读书全书热门划线 Top20，按划线人数降序 |
| 筛选标准 | 独立成句、情感冲击、口语化、适合朗读 |

| 安全 | 无医疗承诺、无绝对化用词、不贬低读者 |

## 与视频的关系

- 每个 `### Quote N` 对应一段实拍素材 + 一条大字字幕。

- `**Time:**` 是预估值，Step Q6 用音频静音检测算出真实时间轴覆盖。

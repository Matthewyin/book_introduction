# 风格卡库

> 每张风格卡是某种插画风格的**常量**。生图提示词 = 选定的风格卡 + 当镜内容，拼接而成。
> 模型只写当镜内容，风格段落逐字节复用，物理上杜绝色板/画风漂移。

## 目录结构

```
templates/styles/
├── README.md                          # 本文件
├── people/                            # 人物线
│   ├── cute-anime-girl.md             # 主力：日系软萌少女（参考：附件图1）
│   └── cute-anime-girl.minimax.md     # MiniMax 专用精简版（备用通道，≤700 字符）
└── pets/                              # 萌宠线
    └── watercolor-cat.md              # 备用：水彩拟人猫（参考：附件图4）
```

## 选风格与审核流程

每集 Step 7.0 开始时：

1. **选风格卡**：根据本集书目类型，从上表选一张。默认 `people/cute-anime-girl.md`。
2. **🔴 审核点⑤b（风格确认）**：展示风格卡全文 + 参考图给用户，用 AskUserQuestion 确认。
3. **生成定妆图**：用选定风格卡走 openrouter 生主角标准像。
4. **🔴 审核点⑤c（定妆确认）**：确认主角形象。
5. **生成测试图**：走 Seedream 通道生 1 张含主角的镜头，验证角色锁定 + 风格一致。
6. **🔴 审核点⑥**：确认后批量。

## 字段规范

每张风格卡必须包含以下字段（英文，直接喂给生图模型）：

| 字段 | 内容 |
|------|------|
| 风格定位 | 媒介、笔触、整体氛围 |
| 色板 | 五色（全库统一）：cream / pink / blue / gold / kraft |
| 人物造型 | 头身比、年龄、发型、服装规则、表情边界 |
| 构图 | full-frame，无强制留白 |
| 禁止项 | 写实/3D/扁平矢量/霓虹/文字/水印等 |

## 新增风格卡

1. 在 `people/` 或 `pets/` 下新建 `.md`。
2. 按字段规范填写，色板必须用全库统一的五色（不得新增 hex）。
3. 附参考图说明（来源、特征）。
4. 更新本 README 的风格卡清单表。
5. 跑 1 张验证图确认效果，再标状态为 ✅ 启用。

## MiniMax 备用通道的长度限制

MiniMax image-01 的 prompt 上限 1500 字符。主力风格卡（~1000 字符）+ 场景内容会超限。
因此 MiniMax 通道（baoyu-image-gen）降级为备用，主力走 dreamina（无长度限制）。

若必须用 MiniMax，为该风格卡额外维护一份 `*.minimax.md` 精简版（≤700 字符），
留余量给场景内容。
